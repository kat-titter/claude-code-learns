# Lessons inbox, the fast store

Cheap capture of feedback moments. The Stop hook (`scan-corrections.py`) appends candidates at the end of each session;
the capture-lesson skill promotes the ones that recur or matter, after generalizing and validating them, and the
weekly watch lists the ones no skill covers yet. Most lines never become skills. Prune freely.

Format: `date · status · "the words it came from" → where it went`

- 2026-06-28 · promoted · "17s/frame seems like a lot" → new skill `macos-long-render`, validated on a second render
- 2026-06-28 · promoted · "there was a citation indexing problem" → new skill `citations` with `check-citations.py`
- 2026-10-14 · promoted · "no dots between words" → `my-style`, Design (taste, not craft)
- 2026-10-20 · promoted · "name each control by what was in the well" → general skill `controlled-comparisons`
- 2026-10-24 · candidate · "why is it taking so long?" → review: one case so far; promote if it recurs
