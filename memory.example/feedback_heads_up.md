Before a download, an install or a job longer than a few minutes, say what it is, how big, and how long, and wait.

**Why:** a 20 GB data pull once started without warning on a laptop with little disk left (2026-10-05).

**How to apply:** measure first (a HEAD request for size, a small run for time), then ask in one line. Related:
[[user-profile]].
